# Factory agent rules

- Always search the skills catalogue via MCP before inventing a process.
- Prefer `get_skill_summary` then `get_skill` for the chosen skill_id.
- Follow the skill procedure; do not skip Inputs / Guardrails sections.
- Do not claim ISO/CMMI/CIS certification; produce gap analysis and evidence only.
- Never commit secrets, tokens, or kubeconfigs.
- Open **draft** pull requests unless the user explicitly asks to merge.
- Keep tenant IDs and org-specific policy out of shared skill templates.
